About

How this base is put together and how to extend it.

The idea

A small, dependency-free starting point for interfaces that must work well on phones first — then scale up gracefully to tablets and desktops. No build step, no framework lock-in.

Project structure

css/ holds tokens, base, layout, component, and responsive styles. js/ holds the app entry point, config, navigation, and reusable components. pages/ holds additional pages that reuse the same shell.

Extending it

Add a page by copying one from pages/, then register it in js/config.js under NAV_ITEMS. The mobile bottom nav picks it up automatically.
